# 匯鹰·量化恢复引擎 MT4｜使用说明

**版本：V1.15｜适用于 MT4｜研究和模拟测试版**

## 这个 EA 是做什么的？

它主要用来**管理已经亏损的持仓**，不是自动寻找第一笔交易机会的普通开仓 EA。

简单理解：选中需要恢复的旧订单 → 达到亏损启动条件 → 按设置尝试锁仓平衡、添加恢复单 → 在满足组合盈利条件时，用恢复单的盈利配合减少部分旧仓。

**它不能保证解套、盈利或避免爆仓。** 遇到持续单边行情，恢复单可能使仓位和风险继续增加。

## 怎样安装和使用？

1. 将 `HuiYing_Recovery_Engine_MT4.ex4` 放入 MT4 的 `MQL4/Experts` 文件夹，在“导航器 → EA交易”中刷新。
2. 在**策略测试器或模拟测试环境**中，将 EA 加载到想测试的品种图表（例如 XAUUSD）。不用安装任何配套脚本或外部 Logo 图片。
3. 打开“输入参数”，先检查**恢复订单筛选范围和魔术号**，确保只选择计划管理的订单。
4. 设置启动条件、锁仓和恢复单参数，观察面板“诊断”页。若显示**“数据未就绪 / 交易禁用”**，说明当前环境不满足执行条件，面板可以显示，但 EA 不进行订单操作。
5. 使用历史数据和模拟环境观察策略行为，重点核查订单数量、仓位变化、手续费及极端行情下的风险。

## 面板上各个按钮有什么用？

| 按钮 | 作用 |
|---|---|
| **总览** | 查看恢复状态、启动条件、锁仓设置 |
| **持仓** | 查看纳入管理的订单和盈亏（数据可用时） |
| **平仓** | 预览下一组可能处理的订单；**这里只看，不会直接平仓** |
| **风控** | 查看点差、滑点、手数与交易准入条件 |
| **诊断** | 查看报价、合约规格和不能运行的原因 |
| **暂停策略处理** | 暂停 EA 后续自动处理，**不会关闭已经持有的订单** |
| **解除人工暂停** | 解除上述暂停；不会绕过其他交易安全限制 |
| **刷新当前页面** | 更新显示内容，不执行交易 |
| **− / +** | 收起 / 展开面板；收起后只保留名称和“+” |

## 几个常用参数

| 参数 | 主要作用 |
|---|---|
| **恢复订单筛选范围** | 决定管理哪些已有订单；用错范围可能选中不该管理的仓位 |
| **恢复启动模式、启动回撤阈值** | 决定什么时候开始恢复；例如 10% 是**启动阈值，不是最大止损** |
| **启用自动锁仓** | 尝试平衡选中仓位的买卖手数；锁仓不等于亏损消失 |
| **恢复单首单手数、恢复单手数倍数** | 决定新增恢复单的大小以及后续增长速度 |
| **恢复网格基础步长点数** | 决定新增恢复单之间的距离 |
| **每份双向平仓手数** | 决定每次计划减少多少旧仓 |
| **每方向恢复单数量上限、单张手数上限** | 限制恢复单数量和单笔大小 |
| **趋势过滤模式** | 可选简单网格、K线过滤或外部指标；外部指标模式需要有有效信号 |

## 使用前必须知道

- **优先在模拟环境验证**，不要只看短期回测盈利。
- EA 主要处理旧仓，不会保证每笔亏损都能恢复。
- 双向锁仓仍会承担点差、手续费、隔夜费和保证金风险。
- 面板显示“交易禁用”时，**不要通过删除安全检查强行运行**。
- 人工暂停是当前 EA 运行期间的控制，不应当作永久止损或自动平仓。

**匯鹰·量化｜独立研发的恢复管理 EA，并非 AW Recovery 官方程序。**
