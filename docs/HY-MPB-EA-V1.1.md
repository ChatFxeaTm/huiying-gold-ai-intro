# 匯鹰·多周期突破挂单 EA V1.1

> 商业版使用说明 · Powered by Huiying Quant

## 产品定位

匯鹰·多周期突破挂单 EA V1.1 面向 MT4 与 MT5，采用 XAUUSD 多周期结构位突破挂单模型。系统由六个独立模块协同工作，可在同一趋势方向上分层参与，同时通过统一风控和成交后保护管理持仓。

## 主要功能

- 六模块 Buy Stop / Sell Stop 突破挂单
- 仅使用已经收盘的 H1 K 线确认结构
- 有效挂单保持原价，不在每个 Tick 重建或追价
- 允许同方向多模块协同
- 存在市场持仓时禁止建立反方向市场风险
- 成交后统一止损、止盈及移动止损管理
- 风险百分比手数、固定手数、组合风险上限
- 单日亏损与连续亏损保护
- 交易时段和周五停止新挂单控制
- 异常锁定、订单重试、CSV 运行日志
- 匯鹰黑金商业面板：中文状态、信号诊断、不开单原因、统计与风控信息
- 面板支持拖动、折叠和展开，最小化恢复不丢失文字

## 平台要求

### MT4

- 将 MQ4/EX4 文件放入 `MQL4/Experts`
- 将 `HY_Eagle_Logo.bmp` 放入 `MQL4/Images`
- 建议加载到黄金品种的 H1 图表
- 首次使用应先加载“只观察不交易”参数文件

### MT5

- 将 MQ5/EX5 文件放入 `MQL5/Experts`
- 将 `HY_Eagle_Logo.bmp` 放入 `MQL5/Images`
- 必须使用 Hedge 对冲账户模式
- 建议加载到黄金品种的 H1 图表

## 首次运行

1. 先选择“只观察不交易”配置。
2. 确认面板显示的品种、周期、点差和结构位状态正常。
3. 确保历史数据加载完整；慢周期模块历史不足时会明确显示原因并停止该模块挂单。
4. 观察至少两个 H1 整点的信号刷新。
5. 正式启用前，根据账户资金和经纪商条件降低风险参数。

## 安全边界

- 不建议在同一账号同时运行两个会自动挂单的相似 EA。
- 默认配置不代表适合所有账户；首次实盘应采用低风险。
- 点差过大、历史不足、交易权限关闭、风控触发或交易时段关闭时，EA 可能不开单。
- 请勿删除或重命名 EA 专用的图表对象和资源文件。
- MT5 非 Hedge 账户不能保持六模块仓位独立。
