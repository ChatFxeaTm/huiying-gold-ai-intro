面向 XAUUSD 的日内黄金交易系统，围绕交易时段过滤、价格行为入场、逆向网格补仓、篮子止盈、移动止损和每日盈利目标管理展开，适合用历史回测和小资金模拟逐步校准。

POSITIONING

黄金专用的日内网格策略。

Super Gold V2.0 的核心思路是先限制交易窗口，再围绕黄金价格波动建立首单和补仓序列，通过篮子止盈与移动止损处理持仓利润，同时用每日盈利目标控制当天交易节奏。

交易品种明确

主要服务于 XAUUSD。黄金波动大、点差和滑点敏感，策略参数需要围绕经纪商报价位数、合约规格和交易时段单独测试。

节奏偏日内

通过 TimeStart 与 TimeEnd 控制开新仓时间，避免全天候无差别进场，便于避开流动性不足或新闻风险较高的时段。

收益靠篮子管理

多单或空单序列按均价与目标距离统一管理，行情回拉到目标区域后整体止盈，减少单笔订单各自为战的问题。

FEATURES

围绕黄金波动设计的关键功能。

这类策略的重点不在单次预测，而在入场过滤、补仓间距、持仓均价、止盈方式和当天盈利目标之间的平衡。

01 方向控制Order 可设置只做多、只做空或多空都做，方便根据账户风格和行情阶段切换。
02 首单过滤以价格行为和距离过滤减少随意开仓，避免在过窄震荡里连续触发。
03 网格补仓价格逆向移动达到 distanceOrder 后按规则补仓，核心风险来自单边行情的持仓扩张。
04 篮子止盈hiddenTakeprofit 可用于统一管理一组订单的目标利润，降低止盈位置暴露。
05 移动止损TrailingStop、TrailingStep 与 TrailStart 负责在已有浮盈后推进保护线。
06 日目标DailyProfitTarget 达到后停止当天继续交易，让收益目标和风险暴露更可控。
07 点差意识黄金策略对点差、滑点和执行速度敏感，实盘前需要加入经纪商环境测试。
08 参数可调手数、间距、时间、止盈和追踪参数都应结合回测结果分品种、分周期保存。

PARAMETERS

常用参数说明。

以下参数适合放在同一套回测模板里横向比较，重点观察最大回撤、连续补仓次数、单日浮亏和恢复速度。

参数参考值用途
Order20 只做多，1 只做空，2 多空都做。
Risk0.05控制基础手数或资金风险比例，建议从更低风险开始测试。
distanceOrder50逆向补仓距离，数值越小，补仓越密，回撤压力越大。
distanceline50首单触发距离，用于过滤过近的价格波动。
TimeStart / TimeEnd6 / 19允许开新仓的服务器时间窗口。
UseHiddenTpfalse是否使用隐藏止盈逻辑。
hiddenTakeprofit60篮子均价止盈点数，用于统一管理一组订单。
TrailingStop25移动止损距离，用于保护已经出现的浮动利润。
TrailingStep50移动止损推进步长，避免过度频繁修改订单。
TrailStart0启动追踪止损的最低盈利点数。
DailyProfitTarget1500.0每日盈利目标，达到后可停止当天新交易。

USAGE

先回测，再模拟，最后小资金验证。

黄金网格 EA 的好坏不能只看盈利曲线，还要看极端单边行情、扩大点差、新闻跳空和连续补仓后的保证金占用。

测试建议

先用 99% 建模质量或真实 Tick 数据回测，分别测试默认参数、低风险参数、扩大点差参数和高波动月份，筛掉回撤过深的组合。

风险提示

网格补仓会在趋势单边时放大浮亏。任何参数都不等于收益承诺，实盘前应先跑模拟账户，并设置最大回撤或最大持仓限制。
