哨兵模式：不是预测涨跌，是防止危险环境乱动。

这一段只讲防御逻辑。哨兵是独立 Python 进程，EA 只读取它输出的权限；危险评分不放在 EA 内计算。

哨兵怎么判断危险

哨兵读取 MT5 的 XAUUSD 行情，只使用已完成 K 线，统一把 ATR、点差、价格距离转成 points，避免 2 位/3 位黄金报价混乱。

行情波动
ATR_M5、ATR_M15 是否异常放大，避免剧烈波动时继续加仓。
价格偏离
Close 与 EMA60、EMA144 的距离是否过大，识别追高追空风险。
结构异常
连续大实体 K、多周期方向冲突、假突破信号都会增加危险分。
执行环境
点差突然扩大、EA 回写订单拒绝或滑点偏高时，也会提高危险等级。

哨兵输出什么

哨兵只输出防御命令，不开仓、不平仓、不读取账户盈亏。账户级风控仍由 EA 自己执行。

danger_score
0-100 的危险环境分数。
danger_level
normal、caution、danger、kill 四个等级。
permissions
是否允许新开仓、加仓、马丁、马丁降档。
reason / features
中文原因和关键特征，清楚说明为什么触发限制。
危险等级 含义 EA 应执行的权限
normal环境正常，危险分较低。允许新开仓、允许加仓、允许马丁。
caution有风险苗头，需要降低攻击性。允许交易，但马丁降档，降低 lot_factor 和马丁倍数上限。
danger危险环境，不适合继续扩张仓位。禁止新开仓、禁止加仓、禁止马丁，只允许已有仓位风控动作。
kill高危或熔断环境。禁止新开仓、加仓、马丁，只保留移动止损、减仓、保本、平仓等防御动作。
升级立即生效 降级连续确认 异常默认 caution 异常禁止马丁

哨兵模式 · 防御控制 · JSON 通讯

哨兵不是交易策略，是给 EA 加权限闸门。

哨兵模式会启动独立 Python 规则评分大脑，读取 MT5 黄金行情，按 ATR、EMA 偏离、点差、多周期冲突等规则计算危险等级，并输出 `hy_ai_command.json`。它不是大模型，也不和主盯盘 AI 共用模型；EA 只读取这个文件决定是否允许新开仓、加仓和马丁，EA 内不计算 danger_score。

它在总链路里的位置

  • 主AI盯盘大脑：调用 DeepSeek / OpenAI，负责中文行情分析和交易观察观点。
  • 哨兵防御大脑：不调用大模型，只负责危险环境评分和权限闸门。
  • 学习观察 V1：只做历史样本影子评分，不参与实时权限控制。
  • EA执行层：只读取 JSON 权限和交易信号，最终执行账户风控。

第一次使用

  1. 打开桌面 `哨兵`。
  2. 主系统的 `立即分析`、`启动盯盘` 可照常使用。
  3. 点击左侧 `哨兵模式`，打开二级窗口。
  4. 在 `Files` 中填写 MT5 公共 Files 目录，通常是 `C:\Users\你的用户名\AppData\Roaming\MetaQuotes\Terminal\Common\Files`。
  5. 点击 `保存配置`，再点击 `启动哨兵`。
  6. 看到 `hy_ai_command.json` 正常更新后，再到 MT5 挂载 `HuiYingGoldAI_Executor V2.4 哨兵版`。
  7. 确认 EA 参数 `InpEnableSentinel=true`，并先用模拟账户验收。
  8. 确认 EA 的日亏损风控保持开启：2% 禁新开、4% 禁加仓/马丁、6% 停机。

MT5 公共 Files 目录怎么找

  1. 打开 MT5。
  2. 点击 `文件 -> 打开数据文件夹`。
  3. 回到上级目录，找到 `MetaQuotes\Terminal\Common\Files`。
  4. 把完整路径复制到哨兵窗口里的 `Files`。

四个危险等级

  • `normal`：允许新开仓、加仓和马丁。
  • `caution`：允许交易，但要求降低马丁强度。
  • `danger`：禁止新开仓、加仓和马丁，只允许已有仓位风控动作。
  • `kill`：高危环境，禁止新开仓、加仓和马丁，只允许已有仓位风控动作。

接入真实 EA 前必须验收

  • Python 哨兵能持续生成 `hy_ai_command.json`。
  • EA 能稳定读取 JSON，并原子回写 `hy_ea_status.json`。
  • 删除 JSON 或关闭哨兵后，EA 必须默认 `caution`。
  • 异常状态下 `allow_martingale=false`。
  • 账户日亏损风控必须优先于哨兵权限生效。
  • 五链路未全部通过，禁止接入真实 EA。
学习观察 V1 · 影子学习 · 商业化闭环

学习观察先积累样本，不直接控制交易。

学习观察 V1 是本地影子学习模块。它读取历史 AI 信号和后续验证结果，学习哪些信号结构更容易有效或失效，并输出 `ai_learning_shadow.json`。V1 不替代主 AI 报告、不替代哨兵、不控制 EA。

怎么使用

  1. 打开软件后，系统会自动扫描历史信号和验证结果，刷新学习状态。
  2. 点击左侧 `学习观察`，打开二级窗口。
  3. 查看质量评分、成功概率、危险概率、学习状态和样本数量。
  4. 如果显示 `样本不足`，继续使用追踪验证功能积累“有效/无效”样本。
  5. 后续点击 `立即分析` 或启动盯盘，学习观察会跟随新信号自动刷新。
  6. 点击 `立即影子评分` 可对最新交易信号手动重新评分。

有没有用到大模型

  • 主AI报告会使用 DeepSeek / OpenAI 这类大模型。
  • 哨兵防御大脑不使用大模型，是规则评分。
  • 学习观察 V1 当前不使用大模型训练，是启动自动扫描的本地轻量学习。
  • 后续商业版可以增加“大模型复盘解释”，但不能让大模型绕过哨兵和账户风控。

它学什么

  • AI建议、信号等级、综合评分、波动风险、方向倾向。
  • 交易状态、是否允许交易、EMA距离、EMA60斜率、布林带扩张。
  • 标签来自追踪验证：`有效` 为正样本，`无效` 为负样本，`中性` 暂不训练。

怎么知道它开始学习了

  • `学习状态` 显示样本不足、类别不足或已训练。
  • `样本概况` 显示可训练样本 / 总匹配样本。
  • `最近影子记录` 会持续记录每次影子评分。
  • `ai_learning_shadow.json` 更新时间会刷新。
  • 达到默认 30 条有效/无效样本，且正负样本都存在后，才会进入本地已训练状态。

商业化边界

  • 样本少时必须明确显示 `样本不足`，不能伪装成已训练模型。
  • 学习观察 V1 只做影子评分，技术字段保持 `controls_ea=false`。
  • 哨兵仍是最终防御层，危险环境下必须限制新开仓、加仓和马丁。
  • 正式商业版需要积累真实成交结果、滑点、订单拒绝和止盈止损样本后再升级。
