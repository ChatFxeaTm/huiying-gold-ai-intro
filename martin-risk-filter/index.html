一个会先判断环境，再决定多空权限的无限网格马丁策略。 An infinite grid martingale that reads the market regime before granting buy or sell permission.

本介绍严格按照 MQ4 代码逻辑整理。EA 每个 tick 同时运行 BUY 与 SELL 两套独立引擎，默认先用内置 Damiani 风格的震荡趋势过滤判断市场状态：震荡允许双向，趋势只允许顺势方向；随后再通过手数、总仓、保证金、篮子止损与逃生模式进行风险约束。 This page is based on the actual MQ4 logic. On every tick the EA runs independent BUY and SELL engines, uses an internal Damiani-style regime filter first, allows both sides in range, allows only trend-following direction in trend, then constrains exposure through lot, basket, margin and escape controls.

代码主逻辑Core Logic

EA 不是单边趋势策略，而是“双引擎并发”的网格马丁。每个方向自己数层、自己找最后开仓价、自己计算均价止盈。The EA is not a one-way trend system. It is a dual-engine grid martingale where each side counts layers, tracks its last entry and manages its own weighted-average exit.

震荡趋势过滤Regime Filter

默认启用。代码内置计算，不依赖外部指标文件。它先判断震荡还是趋势，再用 EMA50 的位置与斜率判定顺势方向。Enabled by default. The calculation is built into the EA and does not require an external indicator file. It first classifies range versus trend, then uses EMA50 position and slope to identify direction.

震荡Range

多单和空单都允许开仓与马丁补仓。BUY and SELL entries and grid additions are both allowed.

上升趋势Uptrend

只允许 BUY 与 BUY 马丁，SELL 被过滤。Only BUY and BUY martingale are allowed. SELL is blocked.

下降趋势Downtrend

只允许 SELL 与 SELL 马丁，BUY 被过滤。Only SELL and SELL martingale are allowed. BUY is blocked.

信号不明Unknown

默认不允许新开单和补仓，除非手动打开“信号不明允许开单”。New entries and additions are blocked unless the unknown-signal override is enabled.

马丁手数阶梯Martingale Ladder

首单使用 InpBaseLot。补仓手数由代码内固定阶梯决定，不完全跟随起始手数。默认 50 层以内，单边理论总手数约 13.07 手。The first order uses InpBaseLot. Add-on lots are defined by a hard-coded ladder and do not fully scale with the base lot. Within 50 layers, default theoretical side exposure is about 13.07 lots.

风险控制与国际化注意Risk Controls and Global Notes

这类策略的核心风险来自连续单边行情、点值差异、杠杆与滑点。代码有多层限制，但默认关闭了账户净值止损和浮亏金额止损，实盘前必须按账户资金重新设置。The main risks are persistent one-way markets, broker point-value differences, leverage and slippage. The code has several limits, but equity stop and floating-loss stop are disabled by default and should be calibrated before live use.

点值依赖经纪商Broker point value

网格、止盈、止损都使用 MT4 的 Point。不同黄金报价位数下，250 点对应的美元距离可能不同。Grid, TP and SL use MT4 Point. For XAUUSD, the cash distance represented by 250 points varies by broker digits.

浮亏止损默认关闭Floating stop off

InpEnableFloatingLossStop=false，InpMaxFloatingLoss=0。默认不会按 EA 浮亏金额触发停机。InpEnableFloatingLossStop=false and InpMaxFloatingLoss=0, so default settings do not stop by EA floating loss.

净值止损默认关闭Equity stop off

InpEnableEquityStop=false，InpMinEquity=0。账户级净值保护需要手动打开并设置金额。InpEnableEquityStop=false and InpMinEquity=0. Account equity protection must be enabled and funded manually.

有效期保护Expiry guard

代码内置 2027-04-20 00:00 有效期检查，超过后 EA 会提示升级并移除。The code includes an expiry check for 2027-04-20 00:00. After that time it alerts for upgrade and removes the EA.
