TrendFollowingEA v1.0 · 双向挂单 · 突破跟随 · 风控辅助

现价上方挂多，现价下方挂空，等待行情自己选择方向。

TrendFollowingEA 是由汇交易策略研发中心整理发布的双向挂单型 EA。策略核心不是主观预测涨跌，而是在当前价格上方预埋 BUYSTOP，在当前价格下方预埋 SELLSTOP，让突破行情触发对应方向订单；同时通过挂单追踪、间距控制、手数递增、盈利平仓和亏损限制，形成一套自动化的趋势跟随交易框架。

STRATEGY LOGIC

策略围绕“突破触发”和“挂单跟随”展开。

EA 每个行情跳动都会先检查账户、时间、点差、杠杆、净值和订单数量等基础条件。条件满足后，它会统计当前品种与魔术编号下的持仓、挂单、方向利润和总利润，再决定是否新挂单、移动挂单或执行平仓保护。

1

现价上方挂多单

当买入方向没有待触发的挂单，并且买单方向浮动情况没有触及限制时，EA 会在当前 Ask + FirstStep 的位置放置 BUYSTOP。只有价格真正向上突破并触及挂单位置，买入订单才会成交。

2

现价下方挂空单

当卖出方向没有待触发的挂单，并且卖单方向浮动情况符合开单条件时，EA 会在当前 Bid - FirstStep 的位置放置 SELLSTOP。价格向下跌破挂单位置后，卖出订单才会成交。

3

每个方向保留一张待触发挂单

策略不会在同一方向无限堆叠未成交挂单，而是先检查 buyStops 与 sellStops。当某一方向挂单数量为 0 时，才会补充新的待触发订单，避免挂单层数失控。

RUNNING FLOW

从筛选环境到平仓保护，EA 先防守再进攻。

这套策略的逻辑顺序很清晰：先确认 EA 允许运行，再确认是否处于交易时间，再评估已有订单和利润情况。只有风控检查通过后，才进入挂单和追踪环节。

STEP 01

运行时间与基础条件过滤

EA 通过 EA_StartTime、EA_StopTime 控制整体运行，通过 Limit_StartTime、Limit_StopTime 控制允许开单的交易时段。同时检查交易是否允许、EA 是否启用、订单总数、点差、杠杆和账户净值。

STEP 02

统计当前订单结构

EA 只管理当前品种且魔术编号一致的订单，分别统计买单利润、卖单利润、买卖手数、持仓数量、挂单数量、最高买入价与最低卖出价，为后续加仓、平仓和挂单追踪提供依据。

STEP 03

盈利与亏损保护优先执行

当总盈利达到 CloseAll，或单向盈利达到 StopProfit 条件时，EA 会执行全部平仓或单向平仓。若总浮亏达到 StopLoss，则触发全平保护。保护逻辑优先级高于继续开单。

STEP 04

按模式控制开单节奏

策略支持 K 线周期模式、秒数间隔模式和无延迟模式。当前版本默认使用无延迟模式 OpenMode = C，即符合条件后尽快检查并补充双向挂单。

STEP 05

挂单动态追踪

如果行情回撤导致挂单离当前价格过远，EA 会用 StepTrallOrders 判断是否需要调整挂单位置，使买入挂单继续保持在现价上方，卖出挂单继续保持在现价下方。

PARAMETER SYSTEM

参数分为距离、仓位、时间、保护四条线。

EA 的参数设计并不是单一开关，而是围绕挂单距离、加仓手数、订单限制和盈利保护建立约束。不同品种、点差、账户规模和交易风格，需要先做回测与模拟验证，再决定是否实盘加载。

订单距离机制

首单用 FirstStep 控制离现价的距离；后续订单根据订单数量和当前浮动情况，在普通间距与第二组间距之间切换。五位或三位报价品种会自动乘以 10，适配报价精度。

  • 首单距离FirstStep_Input = 60
  • 第一组最小间距MinDistance_Input = 120
  • 第一组普通间距Step_Input = 150
  • 第二组普通间距TwoStep_Input = 180

仓位递增机制

首单使用基础手数 lot。后续订单根据 K_Lot 倍数和 PlusLot 递增计算，但最终不会超过 Maxlot。这类设计可以提高趋势行情中的跟随能力，也会放大连续反向波动下的风险。

  • 初始手数lot = 0.01
  • 最大手数Maxlot = 0.04
  • 倍增系数K_Lot = 1.05
  • 手数小数位DigitsLot = 2

盈利与平仓保护

策略包含总盈利平仓、单向止盈、单边利润保护、止损金额和超额利润平仓等机制。代码会优先处理盈利保护与亏损控制，避免在已达到退出条件时继续放大订单。

  • 总盈利平仓CloseAll = 2
  • 单向止盈StopProfit = 1000
  • 止损金额StopLoss_Input = 0
  • 最低净值MinEquity = 10

交易过滤与限制

EA 会限制最大点差、最低杠杆、最大订单总数，也预留了价格上限与下限过滤参数，用于控制过高位置不追多、过低位置不追空。当前代码还保留授权账号与到期时间控制接口，实际启用状态以交付版本为准。

  • 最大点差MaxSpread = 35
  • 最低杠杆Leverage = 100
  • 最大订单数Totals = 5000

RISK DISCLOSURE

风险提示必须放在策略介绍里，而不是藏在最后。

TrendFollowingEA 属于交易辅助工具，不构成投资建议，不承诺收益。任何自动化策略都可能在极端行情、跳空、滑点、点差扩大、网络延迟、平台规则变化和连续震荡行情中出现亏损。

突破挂单可能遇到假突破

策略通过上方买入挂单和下方卖出挂单跟随突破，但市场经常出现刺破后快速回落或反抽的情况，挂单成交并不代表趋势已经确认。

递增仓位会放大回撤

手数倍增和递增机制能提高趋势延续时的跟随能力，但在来回扫损、宽幅震荡或长时间单边反向波动中，也会更快放大浮亏压力。

点差、滑点和流动性会改变结果

实盘成交价格可能与回测、模拟盘不同。重要数据、开盘收盘、节假日流动性不足时，挂单触发与平仓价格都可能出现明显偏差。
